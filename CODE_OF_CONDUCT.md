# Verhaltenskodex

Dieses Projekt lebt vom Mitmachen, auch von Leuten, die gerade erst anfangen. Damit das funktioniert:

- **Respektvoll bleiben.** Kritik an Code, Schaltung oder Konzept ist willkommen, Angriffe auf Personen nicht.
- **Fragen sind erlaubt.** Niemand muss alles können. Wer etwas erklärt, tut das freundlich und ohne
  Herablassung.
- **Ehrlich zum Stand.** Tests und Messwerte so berichten, wie sie sind, auch wenn sie unbequem ausfallen.
  Nichts behaupten, was nicht geprüft wurde.
- **Sicherheit ernst nehmen.** Das Gerät steuert eine Heizung im Fahrzeug. Hinweise auf Risiken sind ein Beitrag,
  keine Nörgelei.
- **Keine persönlichen Daten anderer** (Namen, Fahrzeugkennzeichen, Standorte) veröffentlichen.
- **Rechtliches** (Zulassung, EMV, Produktsicherheit) sachlich diskutieren; Rechtsberatung ersetzt das nicht.

Verstöße kannst du den Maintainern melden (Issue mit Label oder direkt über das Profil der Maintainer). Sie
entscheiden über Ermahnung, das Entfernen von Beiträgen oder den Ausschluss aus dem Projekt.
